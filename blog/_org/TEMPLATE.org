* Writing The Body

Write normally; a blank line separates paragraphs.

A single ~*~ heading becomes an =<h2>= on the page. The post title is already
the page's only =<h1>=, so never write one yourself.

** A Subsection

Two stars nests one level deeper.

* Inline Formatting

*bold*, /italic/, =code=, ~verbatim~, and +strikethrough+.

Links are [[https://finkelsteinlab.org][written with the URL first]], then the
visible text.

A link shows a hover card (title, blurb, image) when its URL is listed in
=_data/link_previews.yml=. Draft the entry with
=./scripts/fetch-link-preview.sh URL=, check it, paste it in. The link in
the post is written exactly as above; nothing else changes.

Footnotes look like this[fn:1].

# NOTE: put footnote definitions at the END of their section. A footnote
# definition swallows everything after it until the next heading, so anything
# placed below one will be absorbed into the footnote.

[fn:1] The footnote text. These get numbered links and a backlink automatically.

* Images

A plain image. Put the file in =assets/images/blog/= and use a site-absolute
path:

[[/assets/images/blog/example.jpg]]

With a caption, which wraps it in a proper =<figure>= with a =<figcaption>=:

#+CAPTION: What this figure shows, and why it is worth looking at.
[[/assets/images/blog/example.jpg]]

With alt text instead of a caption, for screen readers:

#+ATTR_HTML: :alt A description of the image for screen readers.
[[/assets/images/blog/example.jpg]]

# Use CAPTION or ATTR_HTML, not both - together, the attributes land on the
# <figure> and the alt text is silently lost.
#
# Note [[/path][text]] is a LINK to the image, not an image with alt text.

Several captioned images side by side, in a =figures= block. Each gets an
equal share of the width and is cropped square so the row lines up; on a
phone they stack:

#+BEGIN_figures
#+CAPTION: Figure 1a. The first thing.
[[/assets/images/blog/example-a.jpg]]

#+CAPTION: Figure 1b. The second thing.
[[/assets/images/blog/example-b.jpg]]
#+END_figures

# Keep images in a per-post folder, assets/images/blog/<slug>/, resized to
# about 800px on the long edge - the site serves them as-is.

* Video And Audio

There is no native org syntax, so drop to raw HTML. Everything between these
markers is passed through untouched:

#+BEGIN_EXPORT html
<video controls preload="metadata" width="100%"
       poster="/assets/images/blog/poster.jpg">
  <source src="/assets/video/example.mp4" type="video/mp4">
  Your browser cannot play this video.
</video>
#+END_EXPORT

Audio works the same way:

#+BEGIN_EXPORT html
<audio controls src="/assets/audio/example.m4a">
  Your browser cannot play this audio.
</audio>
#+END_EXPORT

# Media must be self-hosted under /assets/. The site's Content-Security-Policy
# allows media from this origin only, so a file hosted elsewhere will be
# blocked and appear broken.
#
# The same escape hatch embeds anything else HTML can do. Third-party embeds
# (YouTube and Google are already permitted; anything else is not) need a CSP
# change in _includes/themes/lab/default.html first.

* Code

Name the language so it gets syntax highlighting:

#+BEGIN_SRC python
def resolve(citekey):
    """Fenced as ```python, highlighted by Rouge."""
    return lookup(citekey)
#+END_SRC

#+BEGIN_SRC bash
rg -n "pattern" --type py
#+END_SRC

For output or plain text you do not want highlighted:

#+BEGIN_EXAMPLE
$ ./scripts/org-to-post.sh blog/_org/my-post.org
  Title: My Post
  Slug: my-post
#+END_EXAMPLE

* Citations

Cite with [cite:@liang_rapid_2015], using a citekey listed in #+BIBLIOGRAPHY
at the top. Several at once: [cite:@liang_rapid_2015;@jiao_noncanonical_2021].

These become numbered links to a bibliography generated automatically at the
end of the post, in Vancouver style. Never write a References section by hand.

* Before You Publish

Delete every section above - they exist only as a reference. What you actually
need is the header block at the top and your own prose.

Then check the preview in both light and dark mode, and confirm your images
and any media actually load.
